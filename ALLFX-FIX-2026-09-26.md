# SpriteStep ALL^ fix — 2026-09-26

## Problem

On the pre-sprite Pattern build, ALL^ could display only the default/zero value and the selected FX could not be edited reliably.

## Fix

1. `native/ui/layout.cpp` now passes `seqPatternSelectedFxCode` into `PatternEditorState` used by the Pattern renderer.
2. `native/ui/input_dispatcher.cpp` opens the Pattern ALL^ picker with the dedicated Pattern FX layout instead of the generic full effect list.
3. `native/ui/fx_helper.h` adds `fx_layout_pattern_all()` containing Pattern-appropriate FX, including REV and DEL while excluding effects already represented by dedicated footer parameters.
4. `native/ui/modules/pattern_editor_tests.cpp` strengthens the ALL^ regression test so the selected FX's current and maximum values are verified before and after editing.
